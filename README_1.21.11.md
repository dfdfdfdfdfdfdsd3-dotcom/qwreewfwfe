# IceVisuals Admin 1.21.11

`icevisual-admin-1.21.11.jar` — отдельная сборка для Minecraft 1.21.11, Java 21+, Fabric Loader 0.19.3 и Fabric API 0.141.6. Обычный JAR без ICEZ, StringVeil, проверки подписки/HWID и требования IceJVM. Для Browser нужен MCEF Modern 0.3.3 для 1.21.11. Не устанавливайте две сборки IceVisuals одновременно.

Сборка для 1.21.4 остаётся в `icevisual-1.0.0.jar`. Архивный `icevisual-ADMIN-РАБОЧИЙ-0717.jar` сохранён.
